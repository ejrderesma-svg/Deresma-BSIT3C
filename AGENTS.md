# Recipe Finder - Project Instructions

This is an Expo/React Native mobile application. Prioritize mobile-first patterns, performance, and cross-platform compatibility.

## Expo Documentation

Expo ships breaking changes every SDK release. Before writing code involving Expo, EAS, or React Native APIs:

1. Read the major version of the expo package in package.json.
2. Read the matching versioned documentation:
   https://docs.expo.dev/versions/v57.0.0/
3. For other Expo documentation, consult:
   https://docs.expo.dev/llms.txt

## Commands

Use bunx instead of npx if the project uses Bun.

```bash
npx expo install <package>
npx expo start
npx expo lint
npx tsc --noEmit
npx expo-doctor
npx expo install --fix
```

Always use expo install for Expo-compatible dependencies.

## Navigation and Routing

Use Expo Router for navigation.

- Routes are located in src/app/.
- Use \_layout.tsx for navigators.
- Keep components, hooks, and utilities outside src/app/.
- Import Link, router, and useLocalSearchParams from expo-router.

Documentation:
https://docs.expo.dev/router/introduction.md

## Building with EAS

Use EAS to build, sign, and submit the application.

```bash
npx eas-cli@latest build
npx eas-cli@latest submit
```

Documentation:
https://docs.expo.dev/eas/index.md

## Rules

- Do not manually create or edit ios/ and android/ folders if they are generated by Expo.
- Configure native behavior through app.json and config plugins.
- Expo Go only supports its bundled native modules.
- Libraries requiring additional native code may need a development build.
- Prefer recommended Expo modules.
- Check SDK compatibility before installing dependencies.

Documentation:
https://docs.expo.dev/versions/v57.0.0/
